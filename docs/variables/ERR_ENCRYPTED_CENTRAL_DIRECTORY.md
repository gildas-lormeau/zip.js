# Variable: ERR\_ENCRYPTED\_CENTRAL\_DIRECTORY

> `const` **ERR\_ENCRYPTED\_CENTRAL\_DIRECTORY**: `string`

Encrypted central directory error

## Remarks

Thrown when reading an archive using the Central Directory Encryption feature of the PKWARE Strong
Encryption Specification, which is not supported.
