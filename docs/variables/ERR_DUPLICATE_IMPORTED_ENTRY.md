# Variable: ERR\_DUPLICATE\_IMPORTED\_ENTRY

> `const` **ERR\_DUPLICATE\_IMPORTED\_ENTRY**: `string`

Duplicate imported entry error (thrown by `{@link ZipDirectoryEntry}#import*()` when two entries of the
zip file claim the same node of the tree and the [ZipDirectoryEntryImportOptions#duplicates](../interfaces/ZipDirectoryEntryImportOptions.md#duplicates) option
is set to `"throw"`)
